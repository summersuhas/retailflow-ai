# RetailFlow AI

RetailFlow AI is a retail inventory management and demand forecasting system built to explore how basic machine learning can be used in retail operations.

The project focuses more on practical workflow, inventory tracking, and dashboard experience rather than complex ML research.

## Live Demo

https://retailflow-ai-sand.vercel.app/

# Features

- Inventory tracking dashboard
- Product stock management
- Demand forecasting
- Low stock alerts
- Sales analytics
- Responsive UI

# Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Python
- Flask
- Scikit-learn
